# Modules Overview Screen

## Product orientation

Модули не должны ощущаться отдельными приложениями. Screen показывает, как каждый блок поддерживает путь:

- Discover — увидеть возможности;
- Advisor — понять возможные matches;
- Resources — проверить факты;
- Tracker — сделать следующий шаг;
- Profile — уточнить контекст.

## Layout

Use a small number of cards with one-sentence purpose, current status and CTA. Avoid technical module names unless they are useful to advanced users.

## State

If a module is not yet connected to real data, label it as preview/limited rather than implying complete functionality.
