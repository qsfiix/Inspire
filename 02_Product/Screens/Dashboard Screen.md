# Dashboard Screen

## First viewport

- greeting and current context;
- primary path focus;
- next best step CTA;
- one short explanation of why it matters;
- visible quality/sync status where relevant.

## Secondary blocks

- recommendations shortlist;
- education system explorer;
- progress/tracker summary;
- recent or saved discoveries;
- quick links to map/resources/profile.

## Responsive behavior

On mobile, primary path and next step come first; map and large grids collapse into list/cards. No critical explanation may exist only in hover.

## Acceptance

A first-time user can identify the next action in under a minute without opening every panel. A returning user can see what changed and resume a path.
