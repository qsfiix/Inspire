# Screen Index

## Screen set

1. Home — value entry.
2. About — mission/trust.
3. Contact — communication.
4. Login/Start — account or guest entry.
5. Onboarding — minimum profile context.
6. Dashboard — personalized overview.
7. Advisor Report — explanation and evidence.
8. Map Exploration — geographic/catalog discovery.
9. Modules/Resources — verified information and connected tools.
10. Tracker — action/progress.
11. Profile — preferences and ownership.

## Definition

A screen is ready when its main job, entry/exit actions, data contract, responsive layout and loading/error/empty states are documented and tested. A visual mock alone is not completion.
