# Typography and Hierarchy

## Hierarchy

1. Page title — один главный смысл экрана.
2. Section heading — группирует блок.
3. Card title — идентифицирует option.
4. Body — объясняет.
5. Metadata/label — trust, category, freshness, status.
6. Helper text — раскрывает ограничение или действие.

## Rules

- Не строить иерархию только на font weight.
- Не использовать uppercase для длинного текста.
- Monospace оставить для технических labels, IDs и engine metadata.
- Учитывать, что немецкий и французский текст может быть длиннее английского.
- Не обрезать критические названия institution/program без доступного полного просмотра.
- Body text должен оставаться читаемым на desktop и mobile.

## Acceptance

Пользователь может быстро отличить название возможности, объяснение, quality state и CTA. При увеличении текста до 200% layout не теряет смысл.
