# Discovery UX

## Discovery loop

Browse → filter → inspect → compare/remember → verify official source → connect to path.

## Information hierarchy

First: name, type, location and relevance. Second: short explanation, language and quality. Third: detailed fields, admissions and links.

## Choice architecture

Start with a manageable set of filters. Show active filters and an easy reset. Preserve user context when moving from recommendation to map.

## Empty discovery

If no records match, explain which filter caused the result, offer reset/general discovery and never imply that no educational options exist in the world.

## Map/list parity

Every map marker has an accessible list/card equivalent. Hover-only information is not acceptable.
