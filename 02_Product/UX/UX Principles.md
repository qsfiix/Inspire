# UX Principles

## UX filters

Before adding a feature, ask:

1. Which user problem does it solve?
2. Does it reduce confusion or add another layer?
3. Does it strengthen personalization, data trust or clarity?
4. Can the user understand what happened?
5. What happens when data is missing or wrong?
6. Is there a smaller MVP version?
7. Can a user undo, edit or leave the flow?

## Priority

User clarity > decoration. Real next step > impressive demo. Honest limitation > confident fiction. Accessible structure > visual novelty.
