# Progress UX

## Progress model

Progress is a sequence of meaningful actions, not a single score:

```text
understand → choose to explore → verify → save → act → reflect → adjust
```

## Feedback

After a task/checklist action show immediate confirmation, updated progress and an optional next action. Keep the user’s agency: do not auto-create goals without consent.

## Avoid misleading signals

Streaks and percentages are local behavior indicators. They are not evidence that a career path is correct or that a person has more potential than another.

## Empty and paused states

A paused path is valid. Explain how to resume or revise it. Never shame a user for inactivity.
