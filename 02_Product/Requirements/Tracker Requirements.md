# Tracker Requirements

## Must-have

- create a goal with title/category/description;
- add checklist items;
- mark items complete;
- show progress and streak carefully;
- edit/remove user-owned local goal;
- show empty and saved states;
- preserve data across refresh in prototype;
- distinguish local from cloud state.

## Later

- calendar integration;
- reminders;
- shared accountability;
- adaptive goal suggestions;
- analytics and habit experiments;
- cross-device conflict resolution.

## Product rule

Tracker is downstream of a meaningful path or personal objective. It should encourage small real actions, not gamify uncertainty or pressure a young user with comparative scores.
