# Page Map

## Page inventory

| Page | Audience | Main job | MVP |
|---|---|---|---:|
| Home | public | understand value and start | yes |
| About | public | understand mission and trust | yes |
| Contact | public | ask a question/partnership | yes |
| Login/Start | public | enter account or guest mode | yes |
| Onboarding | new user | provide minimum personalization context | yes |
| Dashboard | user | see focus, next step and progress | yes |
| Map/Discover | user/guest policy | explore institutions and locations | yes |
| Resources | user/guest policy | access verified official links | yes |
| Tracker | user | turn next step into action | yes |
| Profile | user | manage language, preferences, account | yes |
| Advisor Report | user | understand recommendation evidence | yes |

## Scope rule

The page map is not a promise that every page is fully implemented. `Current Product State.md` is authoritative for current behavior; this file describes the intended product surface.
