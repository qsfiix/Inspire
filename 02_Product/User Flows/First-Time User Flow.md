# First-Time User Flow

## Main path

1. User lands on Home.
2. Reads one clear promise and chooses Start or Explore as guest.
3. If account is needed, sees why and enters auth.
4. Completes minimum onboarding.
5. Reviews what will influence recommendations.
6. Reaches Dashboard.
7. Sees path focus, 2–3 options, reasons and next best step.
8. Opens map/resource or creates a small tracker goal.

## First value moment

The first value is not account creation. It is the moment the user sees a plausible, understandable route and knows what to do next.

## Recovery

Back navigation, refresh, incomplete onboarding, empty data and failed network must preserve agency and provide a next action.
