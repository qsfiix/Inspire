# Tracker and Progress Flow

## Flow

1. User sees a next step or chooses a personal goal.
2. Clicks «Add to tracker» or creates a goal.
3. Adds one or more small checklist items.
4. Marks items complete.
5. Sees progress and optional streak.
6. Returns to dashboard or discovery.
7. Revises/pause goal when context changes.

## Data state

Prototype may save locally. UI always says whether data is local, syncing or cloud-saved. Future cloud flow requires ownership and conflict handling.

## Success

The tracker makes the next action easier to perform; it does not become a separate high-maintenance productivity system.
