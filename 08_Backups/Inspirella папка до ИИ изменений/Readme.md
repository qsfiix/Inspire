# Inspirella

## Что это

Inspirella — это проект, связанный с системным сбором, структурированием, проверкой и использованием данных, данных об учебных заведениях, школах и связанных сущностях.

Этот репозиторий / файловая структура нужен для того, чтобы:
- хранить проект в понятном и устойчивом виде;
- быстро находить нужную информацию;
- разделять стратегию, продукт, данные, разработку и операционную часть;
- снизить хаос при росте проекта;
- упростить подключение новых людей и будущих ИИ-агентов.

## Как пользоваться этой папкой

Если вы открыли Inspirella впервые, идите в таком порядке:

1. Прочитайте этот файл `README.md`.
2. Откройте `PROJECT_MAP.md`, чтобы понять структуру проекта.
3. Откройте `GLOSSARY.md`, чтобы понять используемые термины.
4. Затем переходите в нужный раздел:
   - `00_Brain` — если нужно понять смысл, направление и базовые принципы проекта;
   - `01_Strategy` — если нужно понять приоритеты, рынок, идеи и развитие;
   - `02_Product` — если нужно понять продукт, логику, UX, архитектуру и требования;
   - `03_Data` — если нужно понять сущности, поля, правила импорта, валидации и качества данных;
   - `04_Development` — если нужно понять технические стандарты, структуру кода, тестирование и деплой;
   - `06_Operations` — если нужно понять процессы управления проектом и регулярную работу;
   - `07_Documents` — если нужны дополнительные материалы, заметки, исследования и шаблоны.

## Основные правила структуры

- Названия папок и файлов ведутся на английском языке.
- Содержимое файлов по умолчанию ведётся на русском языке.
- Один файл должен отвечать за одну тему.
- Каноническая информация должна храниться в одном основном месте.
- Если информация устарела, её лучше перенести в архив, чем держать рядом с актуальной версией.

## Статусы файлов

В начале важных файлов используется статус:

- `Canonical` — основной источник правды;
- `Working` — рабочий черновик;
- `Reference` — справочный материал;
- `Archive` — устаревший файл, не использовать как основу для новых решений.

## Базовый принцип проекта

Inspirella должна развиваться не как набор случайных заметок, а как целостная система:
- с понятной миссией;
- с прозрачной логикой продукта;
- с описанными правилами данных;
- с устойчивой структурой разработки;
- с понятными документами, которые можно расширять без потери смысла.
